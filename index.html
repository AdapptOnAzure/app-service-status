PHP's curl uses the operating system's libbrotli1, which no Linux distribution has patched yet, and the .NET runtime bundles a vulnerable copy. Both are exploitable only when an application decodes Brotli data from an untrusted source.

How this is measured

A canary app runs on every built-in Linux runtime version and release channel, 33 in all. Each restarts every 30 minutes and picks up the image currently served on its channel, then reports its runtime version, operating system and the eMudhra roots in each trust store it can read. The .NET canaries also build the chains of the eight compromised intermediates, including their AAA Certificate Services cross-signed copies.

A cell's time is the first report on that channel showing the fix; every later report has stayed fixed. A channel can be patched up to about 30 minutes before the canary sees it.

An application on App Service picks up a patched image only when it restarts.
